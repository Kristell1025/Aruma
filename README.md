# Sistema de Gestión de Inventario y Ventas - ARUMA

## Descripción
Sistema desarrollado en **C#** para administrar los productos de la tienda ARUMA. Permite realizar operaciones CRUD, consultar precios y stock, registrar ventas y almacenar la información mediante archivos de texto. Además, utiliza listas enlazadas simples para organizar los productos.

## Tecnologías
- **Lenguaje:** C#
- **Entorno de desarrollo:** Visual Studio
- **Plataforma:** .NET
- **Control de versiones:** Git y GitHub
- **Almacenamiento:** Archivos de texto (.txt)

## Funcionalidades
- Registrar nuevos productos.
- Buscar productos por nombre, categoría o código.
- Modificar la información de los productos.
- Eliminar productos del inventario.
- Consultar el inventario completo.
- Registrar ventas y actualizar automáticamente el stock.
- Ordenar productos por precio mediante los métodos Burbuja y Selección.
- Guardar y cargar información desde un archivo de texto.

## Estructura del proyecto
- `Program.cs`: contiene las clases y el código principal del sistema.
- `SEM5_C_SistemaAruma.csproj`: archivo de configuración del proyecto.
- `inventario_aruma.txt`: almacena la información de los productos.
